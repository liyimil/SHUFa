# ADR-0004：公开目录 Metadata 复用内容权利门禁

日期：2026-07-18  
状态：已接受

## 背景

M5-02 和 M5-06 要求公开单字与范字详情具有稳定 URL、正确的社交预览和结构化信息。Metadata 不能绕过目录查询边界展示已下架、授权过期、不可用或无来源的图片，也不能为了 SEO 伪造占位内容。

## 决策

- 单字页和范字详情页的 Metadata 与正文调用同一公开目录 API，继承发布状态、真实性等级、权利有效期、公开资产和最大公开尺寸门禁。
- 只有当前 API 响应中存在的公开单字裁切图可以进入 Open Graph/Twitter 图片；无结果、下架、接口失败或没有公开衍生图时不生成替代图片。
- 无结果和失败页面设置 `noindex, nofollow`，不把空结果包装成已收录内容。
- 单字页输出 `CollectionPage`/`ItemList`，范字详情输出 `VisualArtwork` JSON-LD；只包含公开书家、作品、来源、署名和公开图片 URL，不包含数据库 ID、私有原帖键、原图尺寸或内部审核数据。
- JSON-LD 统一转义 `<`，防止内容字段闭合脚本标签。
- 单字路由规范化兼容一次 URL 解码；无效百分号编码、多字和非汉字仍返回无效，保证编码后的固定中文 URL 在 standalone 运行时可访问。

## 结果

搜索引擎和社交平台看到的数据与用户当前可访问的公开目录一致。内容下架或权利变化后，目录标签失效会使 Metadata 重新取数，且不会保留由应用生成的替代图片或无来源描述。
