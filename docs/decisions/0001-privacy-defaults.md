# ADR 0001：用户作品隐私与授权默认值

日期：2026-07-18  
状态：工程基线，仍需上线前法律与未成年人场景评审

## 决策

用户授权分为三个互不联动的维度，并按 `privacy-v1` 留存不可变变更记录：

| 维度     | 默认值 | 当前执行行为                                             |
| -------- | ------ | -------------------------------------------------------- |
| 产品存储 | 允许   | 用于图片质检、对比和练习历史；关闭后后端拒绝新上传       |
| 公开分享 | 禁止   | 开启后才能主动创建公开链接；关闭时撤销该用户全部有效分享 |
| 模型训练 | 禁止   | 不因上传、纠错、反馈或公开分享自动获得训练授权           |

模型训练授权不会改变产品存储或公开分享状态，任何训练数据导出任务都必须按用户 ID 再检查当时有效的训练授权。当前 MVP 没有训练数据导出管线。

关闭产品存储不会静默删除已有作品，因为删除不可恢复。用户通过练习记录逐张确认删除；API 会先在事务中撤销图片访问和相关分享、清除分析衍生数据，再由持久化队列异步清理私有对象。队列失败不恢复访问，并可按删除任务的递增尝试号安全重试。对象存储版本和备份中的最终过期时间仍取决于上线前批准的保留策略。账号级批量导出与删除仍需单独实现。

## 理由

- 产品核心闭环需要短期或持续保存练习图，不能在未实现临时处理链路时声称“关闭后仍可完整使用”。
- 公开传播和模型训练带来的用途变化更大，因此必须默认关闭并由用户主动开启。
- 授权审计只保存维度、开关、政策版本和时间，不保存图片或令牌。

## 上线前待决策

- 匿名用户丢失 Refresh Token 后的数据找回方式。
- 未成年人是否允许开启公开分享或训练授权，以及监护人验证方式。
- 账号级访问、导出、批量删除和备份过期承诺。
