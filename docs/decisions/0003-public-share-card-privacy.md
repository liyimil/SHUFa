# ADR-0003：公开分享结果卡使用最小披露摘要

日期：2026-07-18  
状态：已接受

## 背景

M5-06 和 M8-07 要求公开分享可以被社交平台正确解析并显示结果卡，同时不得泄露受限图片或私人信息。完整分享接口必须返回用户主动公开的练习图片短期签名 URL，但生成页面 Metadata 和 Open Graph 图片并不需要这些地址。

## 决策

- 新增公开分享摘要边界 `/api/v1/shares/{token}/summary`，只返回字符、练习次数、临写书家和碑帖。
- 摘要与完整分享使用同一份不可猜测令牌、过期时间和撤销判断；撤销或过期后两者都返回不存在。
- 摘要生成过程不调用对象存储签名 URL，响应中也不包含练习 ID、作品 ID、范字 ID、用户图片或建议文本。
- 分享页的动态 Metadata 使用中文标题与描述，并设置 `noindex, nofollow`；社交平台仍可根据持有的分享链接读取 Open Graph/Twitter Card。
- Open Graph PNG 只展示练习次数、状态和抽象视觉，不包含用户原图、公开范字图片或任何签名 URL。不可用或服务失败时生成统一的非敏感降级卡片。
- `PUBLIC_WEB_URL` 成为 API 生产必需配置且仅允许 HTTP/HTTPS，防止线上生成 localhost 或非 Web 协议分享链接。

## 结果

公开页面正文仍能按用户主动授权展示短期签名作品图；Metadata 与图片爬虫则只能接触最小摘要。该边界减少了无必要的签名 URL 签发与跨服务传播，并使撤销后的社交预览重新请求时安全降级。
