# ADR-0002：收藏字帖采用单归属分组与稳定排序

日期：2026-07-18  
状态：已接受

## 背景

M8-04 与 M8-05 要求用户可以收藏、取消收藏，并把范字整理成简单的个人练习字帖。首发版本需要行为清楚、移动端操作成本低，同时不能绕过公开内容的发布与权利门禁。

## 决策

- 同一用户对同一范字最多保留一条收藏，重复收藏为幂等操作。
- 一条收藏同一时间只属于一个分组，也可以处于“未分组”；首发不引入标签、多重归属或协作字帖。
- 分组名称在同一用户内唯一，去除首尾空白并折叠连续空白，最长 40 个字符。
- 分组和组内范字都使用整数 `sortOrder`。用户每次只执行上移或下移，服务端随后把同级顺序归一化为连续整数，并以创建时间和 ID 作为稳定兜底顺序。
- 删除分组不会取消收藏；组内范字按原有稳定顺序追加到“未分组”。取消收藏必须显式操作范字。
- 列出收藏时重新应用公开目录的发布、真实性、资产可用性和权利有效期条件。失效内容保留内部关联，但不再向 App 返回图片或元数据。
- 从收藏字帖开始练习时复用公开目录返回的范字结构。若当前已有已保存练习，App 要求用户确认后再清空当前页面状态，避免练习记录和范字错配。

## 结果

该设计覆盖首发的收藏、取消、分组、移动和排序，同时保持数据模型与交互简单。未来若需要标签或多人字帖，应新增独立关联模型和权限设计，而不是改变当前单归属字段的语义。
