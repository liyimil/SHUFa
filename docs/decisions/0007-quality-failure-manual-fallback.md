# ADR-0007：图片质检终态失败降级为手动查字与对比

日期：2026-07-18  
状态：已接受

## 背景

图片安全准入通过后，异步质量分析仍可能因 AI 服务超时、网络故障或无效响应在 BullMQ 有界重试后失败。只记录 Worker 日志会让分析长期停留在处理中，移动端持续轮询。另一方面，把技术失败误写为质检通过会让未知质量图片进入结构建议，产生不可验证结论。

## 决策

- 图片质量 Worker 在最后一次重试失败后，通过内部令牌向 API 发送固定错误码和脱敏、限长的失败诊断。
- API 只允许 `PENDING`/`PROCESSING` 分析转为 `FAILED`，持久化完成时间、尝试数和失败原因；迟到的失败不得覆盖 `PASSED`/`NEEDS_RETAKE`，迟到的成功也不得覆盖 `FAILED`。
- 已通过文件安全准入的作品在质检技术失败后可进入手动确认状态。用户可以确认汉字、检索可靠范字，并使用本地并排或叠加对比；界面必须明确说明没有生成质检结论。
- 创建练习和再次练习仍要求图片质量分析为 `PASSED`。质检失败的降级作品不得进入结构分析、生成建议或保存为已完成练习，用户需要重新拍摄后再继续该闭环。
- 移动端把 `FAILED` 视为终态，立即停止轮询，不把轮询次数耗尽当作成功。

## 结果

AI 或网络故障不会制造永久处理中状态，也不会伪造质量通过或结构建议。用户仍能完成核心的“写字—确认—查找名家同字—手动对比”降级路径；完整建议与练习记录闭环只有在质量门禁真实通过后开放。
